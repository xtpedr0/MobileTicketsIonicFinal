# MobileTicketsIonic



Aplicação mobile para compra e gerenciamento de ingressos desenvolvida com **Ionic Framework**, **Angular (ngModules)** e **Capacitor**.



## 🚀 Tecnologias Utilizadas



- **Ionic CLI**: 7.2.0
- 
- **Angular**: 17.x (com NgModules)
- 
- **Capacitor**: Integração nativa
- 
- **TypeScript**: Linguagem base
- 
- **Sass**: Estilização
- 


## 📱 Funcionalidades



- **Explorar Eventos**: Lista de eventos disponíveis com detalhes e preços.
- 
- **Meus Ingressos**: Visualização dos ingressos adquiridos pelo usuário.
- 
- **Perfil**: Gerenciamento de informações da conta do usuário.
- 


## 📦 Estrutura do Projeto



O código completo do projeto está compactado no arquivo `project_files.zip` presente na raiz deste repositório. Para acessar o código:

1. Baixe o arquivo `project_files.zip`.
2. 
2. Descompacte-o em sua máquina.
3. 
3. Siga as instruções de execução abaixo.
4. 


## 🛠️ Como Executar o Projeto (Após descompactar)



1. Entre na pasta do projeto:
2. 
   ```bash
   
   cd MobileTicketsIonic
   
   ```
   


2. Instale as dependências:
3. 
   ```bash
   
   npm install
   
   ```
   


3. Execute a aplicação no navegador:
4. 
   ```bash
   
   ionic serve
   
   ```
